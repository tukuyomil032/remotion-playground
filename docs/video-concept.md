# MC-Vector 動画の構成

この文書は動画の企画と、現在の構成をまとめています。事実の根拠は `mc-vector-facts.md` を見てください。動画はすべてコードで組み立て、実際のアプリの録画は使いません。

---

## 1. 狙いと視聴者

- 狙い: MC-Vector を「小さくて速く起動し、安全で手軽な Minecraft サーバー管理ツール」と伝える。
- 視聴者: Minecraft サーバーを立てたことのある人。サーバーを持つ友達と遊ぶ人。Mac か Windows を使う人。
- 方針: 音を消して見ても意味が分かること。操作は、分かりやすさを尺より優先する。

## 2. 基本仕様

| 項目 | 内容 |
|---|---|
| 尺 | 128 秒（64 小節）。1 分に収めることはしない。各操作が読めることを優先した |
| 画面比 / 解像度 / fps | 16:9、1920×1080、60 fps、H.264 |
| 言語 | 画面の文字は英語 |
| ナレーション | なし |
| テンポ | 120 BPM。1 拍 = 30 フレーム、1 小節 = 120 フレーム（2 秒） |
| 音 | BGM と効果音はすべてコードで合成する（`scripts/generate-audio.ts`）。外部の素材は使わない |

## 3. 場面の構成

場面の位置と長さは `src/layout.ts` に 1 か所だけ書き、映像（`src/Promo.tsx`）と音（`scripts/generate-audio.ts`）の両方がそこから読みます。

| 小節 | 秒 | 場面 | 内容 |
|---|---|---|---|
| 0–2.5 | 5 | Hook | 面倒な作業の一覧を手書きで書いていく |
| 2.5–5 | 5 | 名乗り | MC-Vector のアイコンと名前 |
| 5–10 | 10 | Speed | 小さなロケットが発射し、宇宙で爆発して、容量と起動時間の数字が出る |
| 10–54.5 | 約 80 | 機能紹介 | 5 つの機能を、文字の場面（3 秒）と操作の場面（14〜16 秒）の組で見せる |
| 54.5–59.5 | 10 | Security | 5 つの安全対策を表で見せる |
| 59.5–64 | 9 | Outro | インストールのコマンドと GitHub |

機能紹介の 5 組は、Create（サーバー作成）、Run（起動と監視）、Extend（プラグイン導入）、Back up（バックアップ）、Share（Ngrok で公開）です。

## 4. 操作の場面の時間の作り方

操作の場面は、窓が右から入ってきて、カメラが寄って、クリックして、また全体に戻り、左へ出ていきます。

- 場面の中身は元の時間で書いてあります。表示のときに、区間ごとに速さを変えて再生します（`Sequence` の `playbackRate` と `trimBefore`）。
- クリックやチャイムの間は、タイムライン上で 50 フレーム（約 0.85 秒）を下回らないようにします。
- 窓が入ってきた直後と、最後のクリックの後に、全体を映したまま止まる時間（80 / 90 フレーム）を置きます。
- 場面の長さは、小節の整数倍に切り上げます。余りは最後の止まる時間に足します。
- 速さと止まる時間の値は `src/layout.ts` の定数（`BASE_RATE`、`MIN_GAP`、`HOLD_START`、`HOLD_END`）で調整できます。

## 5. 画面の作り方

- アプリの画面は録画せず、React と CSS で再現します。アプリの色は `src/app-colors.ts` にあります。
- 動画自身の色は、暖色の「Clay & butter」（`src/theme.ts`）です。バター `#f7e2a6`、墨 `#3b2417`、トマト `#d9482b`、ココア `#7a4a2e`、粘土 `#e8a87c`。青、青緑、紫、ネオンは使いません。
- ロケット、空、雲、地面は、平らな色と墨の縁取りの切り紙風です。
- 煙と爆発だけは、実物らしく柔らかく描きます（`src/speed/Smoke.tsx`、`src/speed/Explosion.tsx`）。ノイズで縁をゆがめた柔らかい円を重ね、色は暖色のままにします。
- 画面の数値は、容量と起動時間以外はすべて作り物です。容量と起動時間は実測値で、測った環境を画面に添えています（`mc-vector-facts.md` の §7）。
- 見せない、言わない内容は `mc-vector-facts.md` の §6 にまとめています。

## 6. 音

- BGM: ピアノ、パッド、細いベースに、やわらかいドラム（丸いキック、ブラシ風のスネア、ハット）を重ねます。機能紹介はハーフタイムのグルーヴ、Speed はカウントダウンから上昇へ盛り上がり、爆発の前後で 1 拍抜けます。
- 効果音: クリック（tap）、完了（chime）、ペン（pen）、ページ（page）に加えて、countdown、ignite、rocket、boom、row を使います。
- 音量の目標は統合ラウドネスが約 -14 LUFS、真のピークが -1.5 dBTP 以下です。

## 7. 決定事項

1. 画面比は 16:9、60 fps。
2. 尺は目安であり、分かりやすさを優先する（現在 128 秒）。
3. 画面の文字は英語。日本語版は未定。
4. ロゴはアプリアイコンの M（`public/brand/icon.png`）。
5. 見せるサーバーソフトは Paper を中心にする。Spigot、Forge、Velocity は映さない。
6. 最後に出すリンクは GitHub と `brew` / `scoop` の 1 行。ドキュメントサイトは出さない。

## 8. 状況

- 全場面、音、結合まで完了。
- 描画: `bun run render`（`out/` に出力。`out/` は git に入れません）。
- 音は聴いての確認がまだです。ビートの強さと、効果音とのバランスは、耳で見直してください。
