# Snapzy 動画の構成

この文書は、Snapzy の非公式デモ動画の企画と作り方をまとめています。事実の根拠は `facts.md` を見てください。動画はすべてコードで組み立て、実際のアプリの録画は使いません。

## 1. 狙い

- 狙い: Snapzy のスクリーンショット、OCR、注釈、動画編集、履歴を、実際に操作している流れで見せる。
- 方針: Apple の製品紹介のような見た目にする。色よりも、Liquid Glass の質感と SwiftUI らしい動きを大事にする。
- 位置づけ: Snapzy の作者とは関係のないファン動画です。最後の画面にそう書いています。

## 2. 基本仕様

| 項目 | 内容 |
|---|---|
| 尺 | 112 秒（56 小節） |
| 画面比 / 解像度 / fps | 16:9、1920×1080、60 fps、H.264 |
| 言語 | 画面の文字は英語 |
| テンポ | 120 BPM。1 小節 = 120 フレーム（2 秒） |
| 音 | BGM と効果音はコードで合成する（`scripts/snapzy/generate-audio.ts`） |
| 文字 | SF Pro（この Mac に入っているものを使う。リポジトリには入れない） |

## 3. 場面の構成

場面の長さは `src/snapzy/layout.ts`、各場面の中のクリックや撮影の時刻は `src/snapzy/timing.ts` に書きます。映像と音の両方がここを読みます。

| 小節 | 場面 | 内容 |
|---|---|---|
| 0–3 | Open | ガラスの滴が流れてきて、アイコン、名前、一行説明が出る |
| 3–10 | Onboarding | 初回起動の 4 段階を進み、「You're All Set!」の後に窓がメニューバーへ吸い込まれる |
| 10–24 | Capture | メニューを開いて撮影方法を一覧し、範囲、アプリのウィンドウ、フルスクリーン、アクティブなウィンドウ、タイマーの順に撮る |
| 24–29 | OCR | ⇧⌘2 で文字を囲み、読み取った文字がガラスのカードに出る |
| 29–39 | Annotate | Quick Access のカードが注釈エディタに広がり、矢印、四角、番号、ぼかし、背景、Mockup を使う |
| 39–46 | Video | 動画エディタで前後を切り、ズーム区間を足し、書き出す |
| 46–51 | History | メニューのガラスが履歴パネルに広がり、絞り込んで、1 枚を開き直す |
| 51–56 | Outro | アイコン、「Free and open source.」、Homebrew の 1 行、URL、対応 OS、ファン動画の表記 |

## 4. 見た目の作り方

- 舞台は Mac のデスクトップです。壁紙は自作の青い波で、macOS の壁紙は使いません。
- ガラス（`src/snapzy/glass/Glass.tsx`）は、背景を縁でゆがめる屈折（SVG の displacement map を `backdrop-filter` に使う）、すりガラスのぼかし、上辺の光、動く鏡面反射、柔らかい影を重ねます。
- 動きは SwiftUI の spring を再現します（`src/snapzy/motion.ts`。`response` と `dampingFraction` から剛性と減衰を出す）。
- 形がつながって変わる動き（メニューバーの項目からメニューが伸びる、Quick Access のカードが編集窓に広がる、オンボーディングの窓がメニューバーに吸い込まれる）を、場面のつなぎに使います。
- アプリの画面は、v2.1.0-beta.6 の画面写真と録画を見ながら React で再現しています（`src/snapzy/ui/`）。
- 撮られる側の窓（メモ、Finder、グラフ）とその中身はすべて作り物です。メールアドレスは `example.com` を使います。

## 5. 操作の速さ

- クリックの間は 50 フレーム（約 0.83 秒）以上あけます。
- 操作の前に、画面全体を見せる時間を置きます。細かい操作のときだけカメラが寄ります。
- 各機能の頭に、大きな見出しを 1 秒ほど出します（例: 「Capture anything.」）。

## 6. 音

- BGM: マリンバ風のプラック、空気感のあるパッド、丸いベース、軽いキックと指パッチン。D メジャー。
- 効果音: tap、shutter、glass、tick、chime、scan、key。
- 音量の目標は約 -14 LUFS、真のピーク -1.5 dBTP 以下です。

## 7. 状況

- 描画: `bun run generate:audio:snapzy` の後に `bun run render:snapzy`（`out/snapzy-promo.mp4`）。
- 音は耳での確認がまだです。
